Microsoft Internship Project – 4 Weeks

Electronics Sales Analysis

📌 Overview

This repository contains the work completed during my 4‑week internship at Microsoft. The project focuses on analyzing customer behavior and sales performance using interactive dashboards and data visualization techniques. The goal was to provide actionable insights into revenue trends, loyalty program effectiveness, and product performance.

🎯 Objectives
- Build interactive dashboards for Customer & Loyalty Analysis and Sales Overview.
- Visualize key metrics such as revenue, order completion rates, and customer demographics.
- Identify patterns in product sales and payment methods.
- Provide recommendations for improving customer loyalty and reducing cancellations.

🛠️ Tools & Technologies
- Power BI (Data Visualization)
- GitHub – for version control and collaboration
  
📊 Key Deliverables

 1.Customer & Loyalty Analysis Dashboard
- Customer counts, average ratings, revenue by gender and age
- Loyalty vs non‑loyalty revenue comparison
- Completed vs cancelled order revenue

 2.Sales Overview Dashboard
- Monthly revenue trends
- Revenue distribution by product type
- Order status breakdown by payment method
- KPIs: total revenue, total quantity, average order value, completion rate
  
🚀 Outcomes
- Discovered that non‑loyalty customers contribute significantly more revenue than loyalty members.
- Identified smartphones and smartwatches as top revenue drivers.
- Highlighted cash payments as having the highest order completion rate.
- Suggested strategies to increase loyalty program adoption and reduce cancellations.

📈 Future Improvements
- Automate data refresh pipelines.
- Integrate predictive analytics for customer churn.
- Expand dashboards with regional and product‑level insights.
